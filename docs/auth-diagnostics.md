# 认证阶段诊断

遇到密码过期、强制改密或未知认证步骤时，可先收集网关返回的有限诊断信息，供维护者确认协议。当前版本不会自动判断密码是否过期，也不会替用户改密码；启用诊断不改变认证结果、退出码、密码重试或会话复用行为。

## 客户如何使用

Windows PowerShell：

```powershell
.\tinyrill.exe run --config .\customer.yaml --auth-debug
```

Linux：

```sh
./tinyrill run --config ./customer.yaml --auth-debug
```

容器在原有 `run --config ...` 参数后追加 `--auth-debug`。这是 `run` 的临时命令行开关，默认关闭，无需修改 YAML、开启 `debug: true` 或资源诊断。终端会提示该客户 `session.state_dir` 下 `auth-debug.json` 的实际路径。

诊断在认证请求结束时保存，初次登录失败、返回未支持的步骤或交互中断后也会留下已经采集的信息。连接成功后仍记录受支持的会话检查接口，适合等待定期过期问题出现。进程必须带此开关启动，不能追溯开启前的响应。若本次复用了有效会话，可能没有密码认证响应；不要为采集反复尝试密码。确需重新登录时，先停止实例，再按现有说明清除会话。

问题出现后：

1. 先复制 `auth-debug.json` 留存，**不要先再次带开关启动**：下一次诊断运行会覆盖上一次报告。
2. 检查 `started_at`、`updated_at` 是否属于本次问题，查看 `version` / `commit`；时间使用 UTC。
3. 人工检查并脱敏不希望分享的字段名或服务名。提供这一个文件，以及当时看到的报错、是否仍能用官方客户端登录即可。

不需要提供 YAML、密码、验证码、`session.json`、凭据库或完整终端输出。普通启动不会生成、修改或删除旧诊断文件；排查完成后去掉开关，旧文件可自行删除。若出现 `Unable to save authentication diagnostic`，文件可能未更新，应先检查状态目录权限与空间。

## 记录范围

| 内容 | 行为 |
|---|---|
| 运行信息 | 协议、程序版本与源码提交、开始/更新时间、最后状态与原因 |
| 请求信息 | 固定认证接口路径、时间、连接代次、HTTP 状态；不记录网关地址、URL 参数、请求正文或请求/响应头 |
| 返回码 | 浅层 `code` / `result` / `ErrorCode` / `errcode` / `NextAuth` 等允许字段中的有界整数 |
| 后续认证 | 浅层 `nextService` / `NextService` 中符合 `auth/服务标识` 形式的值；URL、查询参数及其他文本省略 |
| 标志 | 验证码启用标志、`success` 和少数显式密码状态布尔/0/1 字段；只记录原值，不判定过期 |
| 响应结构 | 有界 JSON / XML 字段名、层级、类型；未知字段默认省略值，已知敏感字段标记 `redacted`，不遍历其子树 |
| 网关提示 | 原始 `message` / `Message` 等文字不落盘。`text_signals` 只列出固定词表匹配，如 `password`、`expired`、`密码`、`过期`、`修改`；不是原文摘录或诊断结论 |
| 采集异常 | 固定失败/解析状态和截断标志；不保存原始异常文本或无法解析的响应正文 |

保留的字段名、服务标识及时间仍应人工复核。即使网关把密码或令牌回显在普通 `message` 中，原文也不会进入报告。结构与关键词可能仍不足以确认所有网关版本的改密流程；维护者将依据真实样本判断是否需要进一步采集，不能仅凭字段名或关键词认定过期。

EC 覆盖登录初始化、密码、短信、动态口令、证书与 `update_session`；aTrust 覆盖认证配置、密码、多因素、设备绑定、CAS/OAuth2 回调结果与认证/在线状态检查。不抓取外部身份提供方网页、图片验证码、完整资源列表、业务流量或 TLS 密钥，也不增加网络请求。

## 文件边界

每个客户独立保存；状态目录锁获取成功后才创建报告。文件使用 Unix 0600 / Windows 当前用户专属 DACL 并原子替换，与 stdout 的 JSON 状态流分开。写入失败只提示，不改变登录结果。

只保留本次运行最近 **64 个认证请求事件**，丢弃计数见 `dropped_events`。单个响应最多检查 128 KiB，超过则只记 `body_too_large`；最多 128 个字段、12 层、1,024 个遍历节点，JSON 数组最多 4 项，XML 单节点文本最多 4,096 字节。达到边界标记 `truncated`；异常/动态字段名被过滤时标记 `filtered_names`。截断或缺少字段不代表网关未返回该信息。
