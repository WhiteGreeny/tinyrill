# tinyrill

This fork provides one EC/aTrust VPN session per process, with HTTP and SOCKS5 TCP proxies and strict YAML configuration. It is an implementation candidate; real customer gateways and deployment environments remain subject to acceptance testing.

See the current [usage and implementation notes](README.md), [examples](examples), and [validation record](docs/implementation-status.md). The old upstream TOML options, TUN integration, Shadowsocks and campus defaults are no longer supported.
